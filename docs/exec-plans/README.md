# Execution Plans

โฟลเดอร์นี้เก็บ **แผนงานที่ลงมือทำ** — ต่างจาก `PRD.md` (ขอบเขตผลิตภัณฑ์) และ `ARCHITECTURE.md` (สภาพระบบ)

| โฟลเดอร์ | เก็บอะไร |
|---|---|
| `active/` | แผนที่กำลังทำ · ตั้งชื่อ `YYYY-MM-DD-<slug>.md` |
| `completed/` | แผนที่จบแล้ว — **ย่อให้เหลือ Status / Summary / Verification** เมื่อปิดงาน |
| [`tech-debt-tracker.md`](./tech-debt-tracker.md) | หนี้ทางเทคนิคสะสม — ปลายทางของทุกอย่างที่ "เลื่อนออกไป" |

## รูปแบบแผน (บังคับ)

```markdown
# <ชื่อแผน>
วันที่: YYYY-MM-DD · สถานะ: active
Baseline: <สถานะ gate ตอนเริ่ม — ต้องมีตัวเลข test จริง>

## บริบท
ทำไมต้องทำตอนนี้ — เขียนให้คนที่ไม่มีบริบทอ่านแล้วเข้าใจ

## ลำดับงาน
### PR 1 — <พื้นที่>: <เป้าหมาย>
- <finding> · ระดับ: สูง/กลาง/ต่ำ · รหัส: <เช่น C3>
  **แก้:** <สิ่งที่ต้องทำ>
  **คงเหลือ (บันทึกไว้):** <สิ่งที่ยังไม่ทำและทำไม>

## เลื่อนออกไป → tech-debt-tracker
<รายการ>

## เกณฑ์ต่อ PR
branch → test ก่อน → รัน gate → review → PR (เอกสารอัปเดตใน PR เดียวกัน)
```

**กติกา:**
- ทุก finding ต้องมี **รหัส + ระดับ** และชี้ไปที่หลักฐาน (audit/doc)
- ทุกอย่างที่เลื่อนออกไป **ต้องถูกย้ายเข้า `tech-debt-tracker.md`** ไม่ใช่หายไปเฉย ๆ
- แผนที่จบแล้ว **ห้ามลบ** — ย้ายไป `completed/` และย่อ
