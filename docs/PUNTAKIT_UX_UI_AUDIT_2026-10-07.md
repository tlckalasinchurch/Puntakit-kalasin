## 1. Executive summary

The headline problem of the 2026-10-02 audit is **closed**. That audit found "two competing
design systems": retired blue/navy Tailwind classes (`slate-*`, `blue-*`, `gray-*`), 10–11px text,
hardcoded hex, and pages that broke in dark mode. Today:

- `grep` for raw palette utility classes across `client/src/**/*.tsx` → **0 hits**.
- Hardcoded hex left in app code → **4 files / 8 literal values**, all neutral black-white or the two theme colours
  (`Members.tsx:286`, `Attendance.tsx:279`, `member/MemberHome.tsx:96`, `ThemeContext.tsx:45`).
- Sub-12px real text → none in any screen (only the unused shadcn `ui/calendar.tsx`).
- 44px touch targets, a visible `:focus-visible` ring, a skip link, a real focus trap in `Modal`
  and in the mobile drawer, a `StatusChip` that never encodes status by colour alone, and
  skeleton-vs-spinner discipline are all in place and locked by
  `client/src/ux-audit-regressions.test.ts`, `design-system-consistency.test.ts` and
  `design-tokens.test.ts`.

What remains is a different class of defect, and it clusters in four places:

1. **The dark theme is only half-migrated.** `--color-success` / `--color-warning` /
   `--color-error` are never remapped in `.dark`, so every status chip in the app misses WCAG AA
   in _both_ themes (computed **3.08:1 – 4.51:1**), white-on-success / white-on-warning fills miss
   it too, and `/privacy` + `/terms` are effectively invisible in dark mode (computed **1.04:1**)
   because they still use the legacy `--navy` / `--muted` aliases.
2. **The shell has two keyboard / assistive-tech gaps**, both small fixes: the _closed_ mobile
   drawer stays in the tab order and in the accessibility tree, and every lazy-route navigation
   unmounts the whole shell and drops focus to `<body>`.
3. **Numbers and lists the user is asked to trust are not always true.** Attendance prints a
   hardcoded `5 รอบ/สัปดาห์` KPI that no API returns; Home's "กิจกรรมที่กำลังจะมาถึง" is the three
   _earliest_ events of all time; the Members area filter is built from the 15 rows on the current
   page; the groups CSV silently ignores the date range that the other three exports honour.
4. **Some surfaces promise more than they deliver.** The prayer-request modal promises pastoral
   follow-up, but no shipped screen ever reads a request; a media-only mission submission can only
   be reviewed blind; a published Feed story is `line-clamp-2` with no way to open it.
