## 3. ผลละเอียดแยกบทบาท

### careA (หัวหน้าแคร์)
- หน้าแรก: 3 ไทล์ (เช็คชื่อ, อัปเดตภาพพันธกิจ, สถานะสมาชิก) ลำดับ Tab เริ่มจาก skip-link → เมนู → ธีม → ออกจากระบบ → "ดูทั้งหมด" → ไทล์ ตามลำดับที่อ่านได้
- ชีตภาพ: ไฟล์ `.txt` ได้ข้อความ "รองรับเฉพาะไฟล์ JPEG, PNG หรือ WebP"; เลือก 8 รูปได้ 6 และแจ้ง "เลือกได้สูงสุด 6 รูปต่อครั้ง"; ลบรูปแล้วนับถูก; รูปใหญ่ 3000×2000 เตรียมได้; บันทึกเห็น progress และ toast; ภาพขึ้นแถบ "ภาพพันธกิจล่าสุด" และ `/feed` (ป้าย "ฉบับร่าง" ใน feed)
- สถานะสมาชิก: เห็น 5 คน (เฉพาะกลุ่มตัวเอง); panel มี "ต่ออายุอีก 1 ปี" และ "ไม่ต่อสถานะ" (ไม่มีปุ่มชำระเงิน); focus เข้า panel และกลับมาที่แถวเดิมเมื่อปิด; Esc และปุ่มย้อนกลับทำงาน

### staff (เจ้าหน้าที่)
- บัตรมีเลข: ปุ่มเปลี่ยนรูป/ถ่ายรูป/พิมพ์บัตร; พิมพ์ใส่ class `pk-printing-card` ระหว่างพิมพ์แล้วถอดออกหลังพิมพ์
- บัตรไม่มีเลข: มีปุ่ม "กำหนดหมายเลขสมาชิก" กดแล้วได้ 00005 บัตรและข้อความแนะนำอัปเดตทันที
- เริ่มรอบสมาชิกจาก panel ในรายละเอียดสมาชิก (วิสามัญ/สามัญ), บันทึกชำระเงิน (ตรวจ 50, "abc", ว่าง ได้ข้อความถูกต้อง; 100 สำเร็จ), "ไม่ต่อสถานะ" พร้อมหมายเหตุ สำเร็จและตัวเลขในแท็บอัปเดต

### bodyLead / viewer / ministry
- bodyLead: `/memberships` เห็น 6 คน อ่านอย่างเดียว (ไม่มีปุ่ม); API ปฏิเสธทั้งเริ่มรอบ/ตัดสินใจ/ชำระเงิน/กำหนดเลข/เปลี่ยนรูป/อัปโหลดภาพกลุ่มลูก (403)
- viewer และ ministry: `/memberships` ถูกปฏิเสธที่ route ("คุณไม่มีสิทธิ์เปิดหน้านี้") และ API ตอบ 403; บัตรของทั้งสองได้ `membership: null` (ไม่เห็นสถานะสมาชิก)
- รูปฉบับร่าง: อ่านได้เฉพาะเจ้าของ, staff, ministry (200); viewer, careB, bodyLead ได้ 404 (ไม่เปิดเผยว่ามีอยู่)

## 5. ตัวเลขหลักฐาน

- ไทล์หน้าแรก: ไอคอน 64px/32px, สูง ≥137px, contrast ชื่อ ≥15.8:1, ไอคอน ≥4.98:1
- บัตร: contrast ตัวอักษรจริงต่ำสุด 5.47 (320px) / 5.92 (390px) / 5.61 (1280px), ฟอนต์ต่ำสุด 12px, พิมพ์ 85.6 mm
- สแกน responsive: 12 หน้า × 3 viewport ไม่พบ overflow, contrast ต่ำ หรือข้อความ <12px ในพื้นที่ของ 4 ticket
- สถานะรอ/ผิดพลาด: โหลดช้า มี skeleton (ไม่ว่าง), server 500 มี "ลองอีกครั้ง" และกู้คืนได้, เน็ตหลุดตอนอัปโหลดแจ้งชัดและคงรูป

## 6. ไม่ได้ตรวจ

- อุปกรณ์มือถือจริง, screen reader, Safari/Firefox (ใช้ Chromium เท่านั้น)
- production, ไฟล์ HEIC หรือใหญ่เกิน 10 MB, ผู้ใช้พร้อมกันหลายคน
- ตัวสแกน contrast เป็นค่าประมาณ (พื้นหลังเรียบเท่านั้น)
- เวลาโหลดหน้า ~4.3 วินาทีเป็นของ dev server ไม่ใช่ของจริง
- ไม่ได้อ่านโค้ด server ทุกบรรทัด ตรวจเฉพาะพฤติกรรมของ API
